Communication Should Never Depend on Speech

ALS Patients

Amyotrophic Lateral Sclerosis deteriorates motor neurons, stripping speech and movement capabilities while cognitive sharpness remains completely untouched.

Locked-In Syndrome

A profound state of paralysis where only vertical eye movements and blinks are preserved as the final, critical bridge to the outer world.

Speech Disorders

Aphasia, dysarthria, and vocal trauma can permanently break verbal channels, isolating individuals within their own minds.

Accessibility Challenges

Most assistive software requires complex, expensive eye-gaze tracking cameras or brain implants. We solve this with normal, accessible webcams.

THE PHILOSOPHY

Morse code is the ultimate minimum-movement communication system. Because it operates on a simple binary mechanism—dots and dashes—it demands zero complex coordination. Standard virtual keyboards require users to lock gaze or head-track across dozens of keys, leading to severe visual fatigue. With BlinkMorse, a single muscle group becomes a high-performance keyboard. It is elegant, robust, and requires less cognitive overhead than spelling words symbol by symbol.

HOW IT WORKS

Workflow Timeline

A high-performance pipeline turning ocular dynamics into spoken communication.

01
Stage 01

Face & Eye Detection

OpenCV + dlib

The webcam feed streams directly to a browser-based computer vision engine. OpenCV reads the frames, and facial mapping algorithms isolate 68 structural coordinate landmarks, mapping the precise geometric boundaries of the eyelids.

02
Stage 02

Blink Classification

Linear Support Vector Machine

The system computes the Eye Aspect Ratio (EAR) on every frame. Using a pre-trained Linear Support Vector Machine (SVM), the system evaluates eye-state descriptors, accurately categorizing frames as "open" or "closed" while discarding micro-noises.

03
Stage 03

Morse Code Decoding

Duration Tracker

The system tracks the exact duration of each closed-eye state. Short blinks are classified as dots (•), and sustained blinks are registered as dashes (—). Spacing intervals are monitored to identify breaks between characters.

04
Stage 04

Input & System Integration

Dictionary Module

Character buffers pass instantly to the translation dictionary. Morse patterns are translated to text in real-time, matching sequences against standard alphanumeric profiles to form coherent spelling lines.

05
Stage 05

Text Output

Web Speech Synthesis

The synthesized text is projected on the interface and parsed by the browser's native text-to-speech speaker modules. Speech output is spoken aloud instantly, completing the loop from sight to sound.

METHODOLOGY

Research & Development Timeline

A linear review of the model evaluation results and pipeline testing parameters.

Phase 1

Dataset Preparation

600 Test Samples

We established a dataset consisting of Open Eyes and Closed Eyes configurations. Pre-processing steps downsampled inputs to 64×64 grayscale formats, compiling them as flattened numerical feature vectors.

Phase 2

Face & Eye Detection

68-Point Facial Landmarks

Ocular locations are scanned in real-time. The system deploys dlib grids combined with OpenCV frame capture to isolate regional eyelid parameters and coordinate vectors.

Phase 3

Blink Classification

Linear Support Vector Machine

A Linear SVM separates blinking and open-eye feature subsets. This model is exported using pickle and joblib modules for resource-efficient deployment.

Phase 4

Model Evaluation

97.67% Accuracy

During testing across 600 samples (360 open / 240 closed), the SVM demonstrated an accuracy of 97.67%, a precision of 97.27%, recall of 98.89%, and an F1 score of 98.07%. The ROC–AUC reached 0.9991, with only 10 False Positives and 4 False Negatives.

Phase 5

Morse Translation

Dictionary-based Lookup

Binary pulse outputs translate straight to characters. The decoder parses dot and dash sequences using search trees mapped from key mappings, outputting correct English sentences.

Phase 6

Future Scope

Multimodal Expansion

Future development phases plan for deep learning integration (CNN/LSTMs), bluetooth integration for active wheelchair systems, custom user-specific thresholds calibration, and voice synthesis extensions.
